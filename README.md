# Давление

Мобильное приложение для ведения дневника артериального давления в светлом стиле Coral Glass. Оно хранит измерения локально, показывает историю и статистику, а также поддерживает экспорт и резервное копирование данных.

## Версия 0.7.1

- периоды экспериментов попадают в резервную копию JSON и в книгу Excel отдельным листом;
- в таблице измерений появилась колонка периода;
- поправлены отступы переключателя автокопии и кнопки редактирования заметки;
- при вводе заметки экран поднимается над клавиатурой;
- под заголовками «Средние значения» и «Диапазон» видно, какой период и сколько записей взято.

## Версия 0.7.0

- периоды экспериментов: история делится на отрезки «без всего», «кофе», «энергетик», «алкоголь», «всё вместе»;
- сравнение каждого периода с чистой базой по давлению, пульсу и самочувствию;
- цветные полосы периодов на графике давления и метки периода на карточках измерений;
- при первом запуске уже прожитые периоды восстанавливаются по заметке «Начало эксперимента»;
- автоматическая копия JSON в «Файлы» после каждого измерения, с переключателем в настройках;
- хранятся текущая копия и семь последних дневных, пустой базой копия не затирается;
- заметку сохранённого измерения теперь можно изменить или дописать;
- при сохранении измерения появляется анимация подтверждения с тактильной отдачей;
- в статистике добавлен выбор периода: неделя, месяц, три месяца или все записи;
- графики аккуратнее ведут себя при большом количестве точек.

## Версия 0.5.1

- экспорт CSV заменён настоящей книгой Excel `.xlsx`;
- кириллица больше не зависит от выбранной Excel кодировки;
- в таблице указаны единицы измерения, настроены ширина столбцов, дата и автофильтр.
- запись файла переведена на совместимый с Expo Go способ;
- если экспорт снова завершится ошибкой, приложение покажет её точную причину.

## Что работает

- одиночное измерение или серия из 2–3 замеров;
- отдельный ввод систолического, диастолического давления и пульса;
- собственная цифровая панель без курсора и подчёркиваний в карточках;
- автоматическая текущая дата и время с возможностью изменить их;
- оценка самочувствия от 1 до 10, готовые отметки и заметка;
- локальное хранение в SQLite;
- история и подробный экран каждого измерения или серии;
- графики давления, пульса и самочувствия;
- статистика с выбором периода;
- эксперименты: периоды, их сравнение и разметка истории;
- экспорт Excel, резервная копия JSON и восстановление из неё;
- автоматическая копия JSON в «Файлы», которую можно отключить.

## Запуск на Windows

Требуется Node.js и приложение Expo Go на iPhone или Android.

```bash
npm install
npx expo start
```

После запуска:

1. Подключи компьютер и телефон к одной сети Wi‑Fi.
2. Отсканируй QR-код камерой iPhone или из Expo Go на Android.
3. Сохраняй изменения в VS Code или Codex — экран обновится через Fast Refresh.

Если локальная сеть блокирует соединение:

```bash
npx expo start --tunnel
```

## Проверки

```bash
npm run typecheck
npm run lint
npm test
```

Для `npm test` нужен Node.js 22.13 или новее. Проверки используют SQLite в памяти и не затрагивают данные приложения.

История загружает записи порциями по 200 через «Показать ещё», а счётчик учитывает всю базу.
Кнопка фильтров слева от «+» позволяет менять порядок записей по дате, систолическому,
диастолическому давлению или пульсу, а также выбирать диапазон дат включительно.
Фильтры применяются ко всей истории; счётчик показывает количество подходящих записей.
На главной график и средние используют последние 12 измерений (или все доступные, если их меньше).
Периоды не могут пересекаться; новый период закрывает предыдущий открытый. Начальное
восстановление периодов выполняется однократно, поэтому удалённые периоды не появляются снова.
Автокопия обновляется также после изменения периодов. Средние на экранах и в Excel
рассчитываются из исходных средних серий, с округлением только итогового значения;
самочувствие показывается с точностью до десятых. Серия содержит от двух до трёх замеров.

## Установочная iOS-сборка

Проект подготовлен для Ad Hoc-сборки через EAS Build:

- Bundle ID: `app.eggplant4287.coral6481`;
- профиль сборки: `adhoc`;
- сертификат и provisioning profile берутся из `ios/certs`;
- `credentials.json` и файлы подписи исключены из Git.

Перед первой сборкой:

1. Создай резервную копию JSON в текущей версии, запущенной через Expo Go.
2. Установи зависимости командой `npm install`.
3. Войди в свой аккаунт Expo:

   ```bash
   npx eas-cli@latest login
   ```

4. Запусти Ad Hoc-сборку:

   ```bash
   npm run build:ios
   ```

После завершения открой выданную EAS ссылку на зарегистрированном iPhone и установи приложение.
При первом запуске самостоятельной версии восстанови измерения из резервной копии JSON.

Папку `ios/certs` и файл `credentials.json` нельзя публиковать или добавлять в репозиторий.
