# Давление

Мобильное приложение для iOS и Android с нативными экранами React Native в согласованном стиле «Ясно»: Manrope, светлый фон, оливковые акценты, синий пульс и золотистое самочувствие. Измерения и настройки хранятся локально в SQLite. Веб-макет остаётся эталоном интерфейса; мобильное приложение использует его общую модель и словарь переводов, без WebView.

Результаты переноса и границы проверки описаны в [docs/native-migration.md](docs/native-migration.md). Исходники и экспорт JavaScript для обеих платформ проверены; установка, жесты, тактильность и системные файловые окна на физических телефонах ещё требуют проверки.

## Что работает

- одиночное измерение или серия из 2–10 замеров;
- отдельный ввод систолического, диастолического давления и пульса;
- системная цифровая клавиатура с переходами «Далее» / «Готово»;
- автоматическая текущая дата и время с возможностью изменить их;
- оценка самочувствия от 1 до 10, готовые отметки и заметка;
- локальное хранение в SQLite;
- история и подробный экран каждого измерения или серии;
- графики давления и пульса с прямым переходом к измерению;
- статистика по датам или периоду, среднее / медиана, минимум и максимум;
- независимые периоды с названием, значком и цветом, до трёх одновременно;
- сравнение периодов и диапазонов по среднему или медиане;
- независимые сохранённые черновики одиночной записи и серии;
- русский, английский, французский, испанский и немецкий интерфейс;
- экспорт Excel, резервная копия JSON и восстановление из неё;
- автоматическая копия JSON в «Файлы», которую можно отключить.

## Навигация на телефоне

На iOS возврат с подробностей измерения, периода и форм выполняется штатным горизонтальным жестом от левого края. Возврат свайпом из середины экрана выключен; формы открываются в стеке, чтобы использовать тот же жест. На Android используются системная кнопка или жест «Назад» с привычными анимациями платформы; для новой сборки включён predictive back. Перелистывание вкладок свайпом и переход вперёд не добавляются.

Веб-макет в рамке iPhone не воспроизводит эти нативные жесты. Их работа и анимации ещё требуют проверки на устройствах. Нативные черновики сохраняются в SQLite при вводе и восстанавливаются после закрытия формы и перезапуска. При ошибке записи уход с экрана блокируется до успешного сохранения; заметки сохранённых измерений защищены таким же образом.

## Резервная копия

Приложение хранит один файл `davlenie-autobackup.json`. По умолчанию используется прежняя папка документов приложения; нажатие «Папка сохранения» открывает системный просмотр папки; удерживание строки позволяет изменить место сохранения. Копия проверяется при запуске и возвращении из фона, обновляется не раньше чем через полные 24 часа после последнего успешного сохранения. Изменения измерений и периодов, импорт и включение переключателя не обновляют её сразу. Пустой дневник не затирает прежний снимок.

Смена папки переносит сохранённый снимок без изменения даты копирования. Если там уже есть файл с тем же именем, его замена требует подтверждения. Старые дневные файлы приложения сводятся к последнему снимку; посторонние файлы не затрагиваются. Импорт сразу открывает системный выбор JSON-файла. Экспорт XLSX и JSON сразу открывает системное меню «Поделиться» с выбором приложения или сохранением в файлы. Просмотр сохранённой копии содержит дату, количество записей, исходных замеров, серий, дней с измерениями и периодов, с одной кнопкой «Закрыть».

Для системных файловых окон и постоянного доступа к выбранной папке добавлен локальный Expo-модуль `modules/diary-backup`. В Expo Go доступна только папка по умолчанию; новый модуль требует самостоятельной сборки приложения. Просмотр и выбор папок используют локальный модуль, отправка XLSX / JSON — `expo-sharing`; автолинковка проверена для обеих платформ. Swift скомпилирован в установочной сборке 0.8.0 (5); Android и полная проверка файловых окон на физических телефонах ещё не выполнены. Нативная версия и веб используют JSON v2; импорт также читает старые копии v1. Сохраняются параллельные периоды, их оформление и время каждого исходного замера.

Сброс к заводским настройкам с подтверждением удаляет измерения, периоды, черновики, настройки и управляемые приложением резервные копии. Пустой дневник сохраняется после перезапуска. Обычное удаление измерений оставляет периоды и копию. Нижние плашки веб-макета удалены во всех вариантах; ошибки и подтверждения остаются видимыми.

## Запуск на Windows

Требуется Node.js 22.13 или новее и Expo Go с поддержкой SDK 57 на iPhone или Android. Проект использует Expo SDK 57, React Native 0.86 и React 19.2. Для iOS требуется версия системы 16.4 или новее.

```bash
npm install
npx expo start
```

После запуска:

1. На физическом iPhone войди в один и тот же аккаунт Expo на компьютере (`npx expo login`) и в Expo Go (значок аккаунта справа сверху). Это обязательное условие запуска через Expo Go на iOS. Текущий аккаунт CLI можно проверить командой `npx expo whoami`.
2. Подключи компьютер и телефон к одной сети Wi‑Fi.
3. Отсканируй QR-код камерой iPhone или из Expo Go на Android. Если на экране уже есть ошибка входа, после авторизации нажми `Try Again`.
4. Сохраняй изменения в VS Code или Codex — экран обновится через Fast Refresh.

Если локальная сеть блокирует соединение:

```bash
npx expo start --tunnel
```

На Windows Expo CLI не находит глобально установленный `@expo/ngrok` и снова предлагает его установить. Укажи папку глобальных пакетов npm при запуске из PowerShell:

```powershell
$env:NODE_PATH = "$env:APPDATA\npm\node_modules"; npx expo start --tunnel
```

## Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run test:design
```

Для `npm test` нужен Node.js 22.13 или новее. Проверки используют SQLite в памяти и не затрагивают данные приложения.

История показывает записи порциями по 30; сортировка и фильтры применяются ко всему дневнику. Доступны даты включительно, режим записи, период, самочувствие, отметки и наличие заметки. Переход из периода или статистики устанавливает временный фильтр; нажатие «История» в нижнем меню сбрасывает его.

Главная показывает предыдущее измерение, активные периоды и график последних 12 записей. В статистике один выбранный интервал используется для показателей, графика и экстремумов; выбор дат, показателей и способа расчёта сохраняется после перезапуска. Точка графика сразу открывает измерение, возврат сохраняет положение статистики.

Общее количество периодов не ограничено. Лимит трёх пересекающихся периодов проверяет прошлое и будущее; создание нового периода не завершает остальные. Начало включительно, завершение исключительно. Измерение относится ко всем подходящим периодам, серия — целиком по времени первого замера. Изменение границ автоматически меняет состав выборок.

Каждая серия имеет один вес в средних и медиане. Округляются итоговые значения; разница сравнения соответствует показанным числам. Экстремумы учитывают исходные замеры. Excel содержит измерения, исходные замеры и периоды, включая все соответствующие периоды каждой записи.

Первый запуск выбирает язык системы с английским запасным вариантом. Ручной выбор сохраняется отдельно; текущий язык стоит первым в списке. Изменение языка обновляет открытые экраны без сброса данных, черновиков или выбора статистики.

## Установочная iOS-сборка

Проект подготовлен для Ad Hoc-сборки через EAS Build:

- Bundle ID: `app.eggplant4287.coral6481`;
- профиль сборки: `adhoc`;
- сертификат и provisioning profile берутся из `ios/certs`;
- `credentials.json` и файлы подписи исключены из Git.

Для обновления установленного «Давления» сохраняются прежние Bundle ID, команда подписи и профиль зарегистрированного iPhone. Подготовлена версия 0.8.5, номер сборки — 10: английский интерфейс называет приложение Pressure Diary, а подписи дат в карточках сравнения больше не переносятся по буквам. Предыдущая установочная сборка — 0.8.4 (9). Приложение содержит интерфейс и работает самостоятельно, без Expo Go и сервера разработки.

Перед сборкой:

1. Сохрани резервную копию JSON из установленного «Давления» перед обновлением. Данные Expo Go находятся отдельно от данных установленного приложения.
2. Установи зависимости командой `npm install`.
3. Войди в свой аккаунт Expo:

   ```bash
   npx eas-cli@latest login
   ```

4. Запусти Ad Hoc-сборку:

   ```bash
   npm run build:ios
   ```

После завершения открой выданную EAS ссылку в Safari на зарегистрированном iPhone и установи обновление поверх существующего «Давления». Старое приложение не удаляй: удаление очищает его локальные данные. Существующая SQLite-база `blood-pressure-diary.db` обновляется на месте; повторный импорт при обычном обновлении не нужен. Если записи были созданы только в Expo Go, перенеси их отдельно через JSON.

Папку `ios/certs` и файл `credentials.json` нельзя публиковать или добавлять в репозиторий.
