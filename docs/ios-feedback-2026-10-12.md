# Исправления по проверке iPhone, 12 октября 2026

Изменения внесены в общие нативные экраны React Native для iOS и Android. Установленная на iPhone версия 0.8.0 (5) ещё не содержит этих исправлений: новый IPA в этой задаче не создавался. Версия, Bundle ID и подпись не менялись.

## Изменения

| № | Пункт | Результат |
|---|---|---|
| 1 | Подписи графика | Крайние даты сохраняются; промежуточные подписи показываются только при достаточном расстоянии, включая расстояние до последней даты. |
| 2 | Виброотклик | Общая успешная галочка даёт отклик в начале и лёгкий отклик при завершении анимации. При уменьшении движения сохраняются два отклика; при прерывании окна завершающий отклик отменяется. |
| 3 | Клавиатура | Для верхнего, нижнего давления и пульса используется `number-pad`. На iOS добавлена панель «Далее» / «Готово» над цифровой клавиатурой. |
| 4 | Самочувствие | На iOS включён выбор нажатием на шкалу; Android использует штатный выбор на шкале. При сохранении ползунок блокируется. |
| 5 | Ошибки | Исправлен промежуток между ошибкой показаний и карточкой даты. Общие ошибки форм и окон используют согласованные отступы и межстрочный интервал; ошибка копии приведена к общему виду. |
| 6 | Показания | Главная и подробности используют один компонент: дата и время, давление по центру, разделитель, пульс и самочувствие с подписями снизу. |
| 7 | Исходные замеры | У шапки убрана цветная заливка; оставлены приглушённые подписи столбцов и тонкая нижняя граница. |
| 8 | Фильтры истории | Активная кнопка имеет зелёный фон и счётчик условий. Диапазон дат и самочувствия считаются каждый одним условием, отметки — отдельно. Учитывается временный переход из периода/статистики, кроме «За всё время»; сортировка не считается фильтром. |
| 9 | Закрытие окон | Общие нижние окна закрываются движением вниз за полосу или шапку. Короткое движение возвращает окно на место. Выбор языка и просмотр копии используют тот же компонент. Календарь, барабаны и прокрутка содержимого сохраняют собственные жесты. |
| 10 | Сравнение | Вместо кнопки со стрелкой — компактный переключатель «Среднее» / «Медиана» с двумя видимыми вариантами. Выбор сохраняется отдельно от статистики. |
| 11 | Показатели периодов | Три одинаковые по ширине колонки, подписи и значения по центру; одинаковое оформление списка и подробностей периода. |
| 12 | Цвета периодов | Убран синий пресет `#627eaa`, осталось девять цветов. Уже сохранённые периоды с этим цветом сохраняют его. |
| 13 | Нажатия в настройках | Красноватый фон нажатия заменён мягким зелёным, включая выбор языка. |
| 14 | JSON | Добавлена строка экспорта JSON с переводами для всех пяти языков. Экспорт содержит записи, исходные замеры, заметки, периоды и даты в формате v2, совместимом с импортом. |
| 15 | Поделиться | XLSX и JSON сразу вызывают системное меню отправки файла. XLSX содержит три листа: измерения, замеры, периоды. Автоматическая копия и её расписание не изменяются. |

Ручной экспорт берёт актуальный снимок SQLite после завершения очереди записей. Временный файл остаётся доступным получателю после закрытия меню; при последующих экспортах удаляются только собственные файлы старше 24 часов. Сброс удаляет управляемые экспорты обоих форматов; при отказе транзакции их содержимое восстанавливается. Посторонние файлы не затрагиваются.

Проверка JSON выявила потерю времени создания периода при обратном преобразовании общей моделью. Исправлено сохранение `createdAt`; для старых снимков без этого поля используется время начала периода. Регрессия сравнивает восстановленные строки SQLite, включая исходные замеры и даты создания.

## Проверки

- `npm test` — 115 тестов, 0 ошибок. Проверяются настоящий SQLite, JSON/XLSX, ошибки и отмена операций, сохранность копии, сброс с откатом; обработчики формы, фильтров, переключателя, жеста окна и жизненный цикл успешной анимации с заменой системных API.
- `npm run test:design` — 90 тестов, 0 ошибок. Общая модель, календарь, переводы пяти языков и восстановление снимков.
- `npm run typecheck`, `npm run lint`, `git diff --check`.
- `expo export --platform all` — пакеты JavaScript для iOS, Android и web, 17 маршрутов. Это не установочная сборка и не компиляция Swift / Kotlin.
- В React Native Web на отдельном `localhost:43823` проверены 402 и 320 px: график с 12 записями, одиночная форма и серия, ошибка давления, подробности серии и её таблица, зелёная кнопка фильтра со счётчиком, карточки периодов, переключатель сравнения, новые настройки и французские подписи. Проверочная серия 126/84/75 и 122/80/71 показала 124/82/73.
- Пользовательский дневник и исходный веб-макет на `localhost:43821` не использовались для создания или удаления записей. Нативный просмотр имеет собственный тестовый SQLite-дневник на другом порту.

## Проверить после установки обновления

1. На iPhone — цифровую клавиатуру и переходы «Далее» / «Готово», выбор самочувствия нажатием на шкалу, два физических виброотклика при сохранении и завершении периода, уменьшение движения.
2. Закрытие фильтров, сортировки, календарей, показателей, выбора периода, языка и просмотра копии свайпом вниз за шапку; короткий/отменённый свайп, прокрутку содержимого и клавиатуру. Браузерный просмотр не подтвердил физический жест; тесты проверяют обработчики с заменой системных примитивов.
3. XLSX и JSON через «Поделиться»: отмену, «Сохранить в Файлы» и передачу выбранному приложению; затем импорт JSON в отдельный тестовый дневник. Файловое содержимое и параметры Share проверены тестами, фактическая отправка на телефоне ещё не проверена.
4. На Android повторить клавиатуру, ползунок, нижние окна, системный возврат и отправку файлов. Проверить большие системные размеры текста и края экрана на обеих платформах.

Коммит, push и установочные сборки выполняются отдельным запросом.
