# Четыре уточнения после проверки iPhone — 13 октября 2026

Исправления относятся к общим нативным экранам React Native. Установленная сборка 0.8.1 (6) ещё содержит прежнее поведение; новый коммит и установочная сборка в этом этапе не создавались.

## Клавиатура показаний

Общая `InputAccessoryView` с одним ID была назначена всем числовым полям. Проверка установленного исходного кода React Native 0.86.3 показала, что Fabric-компонент этой панели ищет первое подходящее поле и привязывается к нему. Поэтому прямой вход в нижнее давление не обеспечивал собственную кнопку «Далее».

Общая панель удалена. Каждое числовое поле задаёт штатную подпись iOS через `inputAccessoryViewButtonLabel`: «Далее», кроме последнего пульса — «Готово». `number-pad` сохранён. Действие вызывается через обработчик самого поля, без зависимости от очередности `onFocus` / `onBlur`. Добавление или удаление последнего замера серии пересоздаёт только соответствующее поле с новой подписью; введённые значения остаются в черновике. На Android сохраняются стандартные действия цифровой клавиатуры.

## Захват шторки

Верхняя полоска находится внутри отдельной области высотой 36 px на всю ширину окна. Область не сворачивается оптимизацией нативных View и захватывает касание сразу при старте; сама декоративная линия не перехватывает события. Пока шторка перемещается, захваченный жест не передаётся прокрутке содержимого. Короткое движение возвращает окно на место; достаточное движение вниз закрывает окно. При сохранении занятого окна закрытие по-прежнему блокируется.

Кнопка закрытия и остальное содержимое расположены отдельно от области захвата. Календарь, барабаны и прокрутка не получают обработчик перетягивания шторки.

## Статистика и настройки

- «Показатели» — компактная светлая кнопка с лёгкой рамкой и скруглениями. Стрелка выполнена SVG и расположена по центру по высоте; символьная стрелка из текста удалена.
- У нажатий строк настроек и вариантов языка убрана цветная заливка. Фон сохраняется; во время нажатия меняется только прозрачность строки до 0,72. Постоянные признаки выбранного языка и включённой автоматической копии сохранены.

## Проверки

- `npm test` — 117 тестов, 0 ошибок. Дополнены регрессии прямого входа в нижнее давление и перехода к пульсу, изменения «Готово» на «Далее» при добавлении замера серии, немедленного захвата полоски и блокировки жеста занятого/скрытого окна. Эти тесты заменяют системные примитивы; физическую клавиатуру они не открывают.
- `npm run typecheck`, `npm run lint`, `git diff --check`.
- Локальный `expo export --platform all` создал пакеты JavaScript iOS, Android и web с 17 маршрутами. Swift / Kotlin и установочный IPA не собирались.
- React Native Web на прежнем `localhost:43823`: статистика проверена на 402 и 320 px; кнопка показателей не переполняет строку, смещение центра SVG-стрелки относительно центра кнопки равно 0 px.
- Окно показателей закрыто перетягиванием непосредственно за видимую полоску. У выбора языка короткое движение сохранило окно, длинное — закрыло. В браузере используется перетягивание мышью; касание на iPhone требует новой проверки устройства.
- При удержанном нажатии строки языка в настройках фактически измерены одинаковый фон `rgba(0, 0, 0, 0)` до/во время нажатия и изменение прозрачности с 1 до 0,72.
- Исходный дневник на `localhost:43821` не изменялся. Отдельный тестовый SQLite-дневник на 43823 сохранён после обновления просмотра; записи не добавлялись и не удалялись.

После новой установочной сборки на iPhone проверить прямое открытие нижнего давления, «Далее» / «Готово» в одиночной записи и серии, перетягивание именно за полоску во всех нижних окнах и отсутствие цветной вспышки при нажатии настроек.
