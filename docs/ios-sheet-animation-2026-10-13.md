# Затемнение нижних окон — 13 октября 2026

После установки 0.8.2 (7) пользователь заметил, что затемнение движется вслед за нижним окном и исчезает с задержкой, особенно при открытии. Исправление относится к общему нативному `Sheet`, поэтому действует в фильтрах, выборе дат, показателей, языка и остальных окнах текущих экранов React Native.

## Изменение

У системного `Modal` отключена анимация всего контейнера. Затемнение вынесено в отдельный неподвижный слой на весь экран; только карточка окна получает вертикальное смещение. Открытие и закрытие одновременно меняют положение карточки и прозрачность фона через `Animated.parallel` с одинаковыми длительностью и easing, на нативном драйвере.

Первое открытие ждёт и `onShow`, и измерения фактической высоты карточки. Модальный контейнер сначала скрыт и монтируется после подготовки анимации, в том числе у окна, впервые добавленного на экран уже с `visible=true`. Короткое окно не начинает движение с высоты всего экрана. Во время перетягивания прозрачность фона связана с пройденным расстоянием, сам фон не перемещается. Короткий жест возвращает обе части на место.

Закрытие за полоску, по крестику, фону и системной кнопке назад завершает общую анимацию прежде, чем вызывает `onClose`. Это позволяет плавно закрывать и те окна, которые родитель удаляет из дерева компонентов. Изменение `visible` у остающегося компонента тоже использует общую анимацию. Повторное открытие отменяет старое закрытие; размонтирование отменяет устаревшие завершения. Замена колбэка родителя не пересоздаёт обработчик текущего жеста. Блокировка закрытия занятого окна сохранена.

## Проверки

- `npm test` — 126 тестов. Девять новых сценариев проверяют порядок `onShow` / `onLayout` / подготовки видимости, синхронное изменение двух слоёв, удержание модального контейнера до завершения, короткий жест, закрытие без второй анимации, повторное открытие, отмену после размонтирования, Strict Mode и обновление колбэка родителя. Системный Animated заменён управляемым тестовым примитивом; это не проверка частоты кадров на iPhone.
- `npm run typecheck`, `npm run lint`, `git diff --check` прошли. Локальный `expo export --platform all` создал пакеты JavaScript iOS / Android / web с 17 маршрутами. Установочная сборка в этом этапе не запрашивалась.
- React Native Web на отдельном `localhost:43823`, 402 и 320 px: проверены короткое окно показателей и высокое окно дат, первое открытие, закрытие по крестику и фону, короткий возврат и полное перетягивание за полоску. После закрытия модальный слой отсутствует.
- При открытии на 402 px измерены высота карточки 424 px, смещение 387,9716 px и opacity затемнения 0,0849727. При удержанном смещении 60 px opacity равна 0,858491. При закрытии окна дат на 320 px: высота 680 px, смещение 566,865 px и opacity 0,166375. Во всех этих состояниях затемнение занимает весь экран от `(0, 0)` и не имеет transform; расхождение нормализованных смещения и прозрачности меньше 0,000001.
- Снимки `sheet-backdrop-fixed-402.jpg`, `sheet-range-320.jpg` и измерения `sheet-motion-checks.json` сохранены в папке артефактов чата. Записи и настройки тестового дневника не добавлялись и не удалялись; основной макет на 43821 не менялся.

Коммит, push и установочная сборка не выполнялись. Текущая установленная 0.8.2 (7) сама по себе этого исправления не получает.

Для приёмки после новой установки проверить открытие и закрытие короткого окна показателей и высокого окна дат, медленное перетягивание, короткий возврат, крестик, фон и системный возврат Android. Затемнение должно оставаться на месте и исчезать вместе с карточкой. Плавность на физических устройствах требует повторной проверки.
