## Хранение и совместимость

SQLite сохраняет существующие записи при добавлении столбцов значка/цвета периода и времени замера. Экспорт JSON v2 и импорт v1/v2 проверены обратным преобразованием через модель веб-макета. Принадлежность периодам рассчитывается по датам: начало включительно, конец исключительно; серия относится целиком по первому замеру. Измерения пересекающихся периодов не дублируются в общей статистике.

Сохранение записи и очистка только её черновика выполняются одной транзакцией. Очередь защищает одновременные изменения и восстанавливается после отказа. Повреждённые черновики сохраняются без перезаписи и показывают ошибку; неверные настройки статистики восстанавливаются по отдельным полям. Сбой чтения после успешной вставки предлагает повторить загрузку без повторной вставки. Сброс откатывает данные и копию при проверенных ошибках; бинарный XLSX восстанавливается побайтно.

## Приёмка на устройствах

Первый запуск на iPhone дошёл до экрана истории и выявил отсутствие `Intl.PluralRules` в фактической среде Expo Go. Общий счётчик исправлен запасными правилами пяти языков; тест сначала воспроизвёл отказ, затем проверил соответствие обычному Intl без этого API. После исправления пройдены 103 нативных и 90 веб-тестов, typecheck и lint, обновлённый пакет iOS доступен по прежнему HTTPS-туннелю. Повторное открытие истории после исправления и остальные сценарии ниже ещё требуют подтверждения на устройстве.

Полная проверка на физических телефонах ещё не выполнена. Самостоятельный iOS IPA собран 12 октября; подробности и проверки указаны выше. Android APK пока не создавался.
